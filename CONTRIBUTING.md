# Contributing

Thanks for your interest in contributing to `nukapy`.

This project is in early scaffold stage. For now, prefer small, focused pull requests that move one planning item forward at a time.

## Development

```sh
uv sync
just quality
```

## Tooling

- `uv` manages dependencies and command execution.
- `ruff` handles formatting and linting.
- `pyrefly` handles type checking.
- `pytest` handles tests.
